# 黃宥瑄 Shelley｜個人作品集網站

Bootstrap 5 一頁式響應式網頁（基礎網頁設計 本週加分作業）。

🌐 **線上網址：https://shelley56744.github.io/portfolio/**

## 怎麼打開
1. 用 VS Code 打開整個 `shelley-portfolio` 資料夾
2. 在 `index.html` 按右鍵 →「Open with Live Server」（沒有的話先安裝 Live Server 擴充功能），或直接雙擊 `index.html` 用瀏覽器開
3. 需要連網，Bootstrap、字型和 Google 地圖都是用 CDN 載入

## 檔案結構
```
index.html      網頁內容
css/style.css   自訂樣式（配色、動畫、響應式）
js/main.js      互動效果（文字逐字出現、視差、表單驗證）
images/         照片、作品圖、金魚／星星／花等 SVG 插圖
```

## 作業要求對照
| 要求 | 位置 |
| --- | --- |
| Navbar 導覽列 | 頁面最上方，手機版收合成漢堡選單 |
| Carousel 輪播圖 | 精選作品區上方 |
| Card 卡片 | 專長區、作品區（手機 1 欄／平板 2 欄／桌機 3 欄） |
| Form 表單 | 聯絡我（輸入框、下拉、單選、複選、驗證） |
| Modal 彈出視窗 | 作品卡片「看更多」、表單送出後的感謝視窗 |
| Accordion 手風琴 | 經歷區 |
| Google 地圖 | 頁尾 |
